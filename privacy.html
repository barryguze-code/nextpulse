Privacy Policy

Effective: August 24, 2026

NextPulse is an internal manufacturing and inventory application operated for Aşhane. This policy explains how the NextPulse Gmail Order Import integration uses Google user data.

Google data we access

With the mailbox owner's authorization, the integration accesses Gmail messages in the configured company order mailbox that match the order-import search and contain PDF attachments.

How we use the data

  • Read matching order emails and PDF attachments.
  • Parse BİM order information, including order number, dates, branch, delivery address and order lines.
  • Create sales-order records in NextPulse and prevent duplicate imports using message identifiers.
  • Mark successfully processed messages as read.

Storage and sharing

Imported business-order data is stored in the protected NextPulse database and is available only to authorized company users. Google user data is not sold, used for advertising or shared with unrelated third parties.

Security and retention

OAuth credentials and application data are protected with restricted server access. Data is retained only for operational, accounting and legal needs. Access can be revoked at any time from the Google Account security settings.

Contact

Questions or deletion requests: nextai.ashane@gmail.com
